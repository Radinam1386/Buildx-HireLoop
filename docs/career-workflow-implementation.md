# نسخه بعدی HireLoop — پنج قابلیت تأییدشده

دامنه از درخواست «هر ۵ تارو بزن» و طرح قبلی می‌آید. همه تغییرها در همین checkout انجام می‌شوند تا نسخه ساخته‌شده و تغییرهای قبلی حفظ شوند؛ فایل env، داده کاربران و کارهای قبلی حذف نمی‌شوند. وابستگی تازه لازم نیست. API مدل فقط با اقدام صریح کاربر، با ثبت مصرف و ذخیره نتیجه فراخوانی می‌شود.

1. تحلیل آگهی: متن اصلی یا متن کامل واردشده، تفکیک ضروری/ترجیحی و شرایط، نقل‌قول قابل بررسی، نمایش وضعیت شاهد/نامعلوم. GET بدون AI؛ POST صریح با نتیجه ذخیره‌شده و fingerprint متن. تحلیل کاربر خصوصی است.
2. رزومه: منابع از پروفایل و جواب تأییدشده، شناسه منبع کنار ادعا؛ نمایش ابهام بدون تضمین صحت معنایی. ویرایش مستقیم با version برای جلوگیری از بازنویسی هم‌زمان؛ متن قبلی و جدید قابل مرور. ویرایش دستی تأیید کاربر است و به AI نیاز ندارد.
3. تمرین: مسیر مستقل از دریافت سابقه؛ پنج سؤال مربوط به آگهی/پروفایل، پاسخ کاربر قبل از پاسخ نمونه، بازخورد و سؤال تکمیلی محدود، جلسه و نتیجه خصوصی و ماندگار؛ خطای provider پاسخ قبلی را از بین نمی‌برد. GET بدون AI و ادامه با نسخه جلسه.
4. رهگیر: وضعیت، تاریخ، یادداشت، نسخه و تصویر ثابت رزومه ارسال‌شده؛ مشاهده لینک به معنی ارسال نیست. هر کاربر فقط درخواست‌های خودش را می‌بیند؛ تغییرها بدون AI.
5. ورود/خروج: چسباندن متن رزومه، استخراج پیشنهادی و بازبینی قبل از ذخیره، حفظ داده خصوصی و تاریخچه. PDF از چاپ بومی با صفحه‌بندی خوانا، Word واقعی DOCX با stdlib؛ فارسی RTL و انگلیسی LTR. هیچ اطلاعات داخلی در خروجی نباشد.

تقسیم کار و قرارداد:

- analysis.py + JobAnalysis.jsx و JobDetail.jsx: router /api/jobs/{id}/analysis (GET/POST)، cached_analysis(db,user,job) بدون AI؛ ماژول مالک جدول تحلیل خودش. main و App را root متصل می‌کند.
- practice.py + Practice.jsx: router /api/practice برای شروع، مشاهده و پاسخ؛ مسیر /app/practice/:jobId. ماژول مالک جدول جلسه خودش. پنج سؤال، سقف سؤال تکمیلی، جلوگیری از ارسال مجدد همان نسخه.
- applications.py + Applications.jsx + TrackJob.jsx: router /api/applications برای فهرست/ثبت/ویرایش؛ مسیر /app/applications. ماژول مالک جدول خودش و snapshot مستقل رزومه.
- resume_io.py + ResumeImport.jsx: router /api/profile/import (POST پیشنهاد، بدون ذخیره خودکار)، /api/resume/export (GET DOCX). حفظ تغییرهای پروفایل از طریق PATCH موجود پس از مرور.
- root: اتصال router و مسیرها، منشأ/ویرایش رزومه، استفاده از تحلیل ذخیره‌شده در writer، کنترل مشترک UI، تست ادغام و اجرای محلی.

پیش‌بررسی: هر عامل فقط فایل‌های تعیین‌شده خودش را تغییر می‌دهد؛ schema درخواست و جدول مخصوص خودش در همان ماژول می‌ماند. مالک main.py و App.jsx و styles.css و services.py و schemas.py و Resume.jsx فقط root است. قراردادهای مشترک در پیام عامل ثبت و پیش از اتصال بررسی می‌شوند. تست provider با جانشین کنترل‌شده و دیتابیس تست انجام می‌شود؛ آزمون واقعی API محدود و فقط پس از پاس شدن تست‌های محلی است.

پذیرش: نگهداری پس از reload، مالکیت داده، خطا و تکرار درخواست، عدم AI در GET/ویرایش/رهگیر/export، نتیجه قابل مشاهده در مرورگر، pytest کامل و frontend build.

پیشرفت: هر پنج قابلیت متصل و اجرا شدند. بک‌اند FastAPI و فرانت Vite روی 8000 و 5173 فعال‌اند؛ env و داده‌های قبلی حفظ شدند. وابستگی جدید اضافه نشد.
