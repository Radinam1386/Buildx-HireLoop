# HireLoop

نسخهٔ اولیهٔ دستیار فارسی کاریابی بر اساس مهارت‌ها و هدف شغلی شما. یک سرور FastAPI، پایگاه دادهٔ SQLite و رابط راست‌به‌چپ دارد.

ثبت‌نام، ورود، ویرایش و تأیید پروفایل و جست‌وجوی آگهی بدون کلید مدل کار می‌کنند. گفت‌وگوی تطبیقی، مقایسهٔ آگهی‌ها و انتخاب مهارت‌ها و پروژه‌ها برای رزومه به API هرمز نیاز دارند. وقتی اتصال تنظیم نشده باشد، رابط این بخش‌ها را غیرفعال می‌کند؛ پاسخ یا آگهی ساختگی نمایش نمی‌دهد.

## اجرا در ویندوز

Python 3.11 یا جدیدتر نصب باشد. در پوشهٔ پروژه اجرا کنید:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
.\run.ps1
```

اگر فایل `.env` را قبلاً ساخته‌اید، دوباره کپی نکنید. سپس `http://127.0.0.1:8000` را باز کنید. اگر اجرای اسکریپت در PowerShell محدود بود، فرمان مستقیم زیر همان سرور را اجرا می‌کند:

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

## اتصال هرمز و هزینه

در `.env`، کلید `HORMOUZ_API_KEY` و آدرس دقیق OpenAI-compatible سرویس در `HORMOUZ_BASE_URL` را وارد کنید. آدرس باید HTTPS باشد و معمولاً به `/v1` ختم می‌شود. برنامه `/chat/completions` را به آن اضافه می‌کند. آدرس سرویس را حدس نمی‌زند. شناسهٔ پیش‌فرض مدل `gpt-6-luna` است؛ اگر داشبورد هرمز شناسهٔ دیگری دارد، `HORMOUZ_MODEL` را تغییر دهید.

پس از تغییر فایل، سرور را متوقف و دوباره اجرا کنید. کلید فقط در سرور استفاده می‌شود و `.env` در Git نادیده گرفته شده است.

هر پیام گفت‌وگو حداکثر سه درخواست مدل دارد. مقایسهٔ حداکثر ۱۲ آگهی و ساخت یا اصلاح هر رزومه، هرکدام یک درخواست دارند. سقف پیش‌فرض هر حساب ۴۰ تلاش در روز UTC و خروجی هر درخواست ۱۲۰۰ توکن است. تلاش ناموفق هم از سقف کم می‌شود. این سقف تضمین مبلغ ریالی نیست؛ قیمت و اعتبار در هرمز تعیین می‌شوند. تست‌های پروژه هیچ درخواست پولی به مدل نمی‌فرستند.

## مسیر تست دستی

1. حساب بسازید. برای تأیید، «بررسی و تأیید پروفایل» را در گفت‌وگو بزنید، اطلاعات را بررسی کنید و سپس «ذخیره و تأیید پروفایل» را بزنید. تأیید برای ساخت رزومه لازم است؛ جست‌وجو بدون آن کار می‌کند.
2. در «فرصت‌های شغلی» یک عنوان یا مهارت جست‌وجو کنید. لینک، نوع شواهد و وضعیت هر منبع را بررسی کنید.
3. پس از اتصال مدل، گفت‌وگو و مقایسه را امتحان کنید. یک آگهی انتخاب کنید یا متن کامل آن را بچسبانید.
4. رزومه را بررسی کنید. اصلاح رزومه مهارت‌ها و پروژه‌های موجود را انتخاب یا مرتب می‌کند. برای تغییر خلاصه یا سابقه، ابتدا پروفایل را ویرایش و دوباره تأیید کنید.
5. «چاپ / ذخیره PDF» را بزنید و در پنجرهٔ چاپ مرورگر Save as PDF را انتخاب کنید.
6. خارج و دوباره وارد شوید؛ پروفایل، گفت‌وگو، آخرین نتایج جست‌وجو و رزومه‌ها باقی می‌مانند.

مدل اجازه ندارد مهارت، سابقه، پروژه یا خلاصهٔ جدید به رزومه اضافه کند. محتوای رزومه از اطلاعات تأییدشدهٔ شما می‌آید؛ امتیاز تناسب، احتمال استخدام نیست.

در بررسی زندهٔ ۴ اکتبر ۲۰۲۶، جست‌وجوی «فرانت اند» ۱۲ آگهی مستقیم برگرداند: جابینجا ۸، کوئرا ۱ و ایران‌تلنت ۳. دسترسی و تعداد نتایج با زمان و شبکه تغییر می‌کنند. هر منبع حداکثر هشت نتیجه می‌دهد و نتایج پنج دقیقه کش می‌شوند. نگارش‌های «فرانت‌اند»، `frontend` و `front-end` یکسان جست‌وجو می‌شوند.

انتخاب شهر همراه با پذیرش دورکاری، آگهی‌های آن شهر یا آگهی‌های دارای شواهد دورکاری را نگه می‌دارد. بدون شهر، گزینهٔ دورکاری فقط نتایج دارای این شواهد را نگه می‌دارد. نتیجهٔ جست‌وجو، عبارت، فیلترها و خطای هر منبع در گفت‌وگو نمایش داده می‌شوند. اگر جست‌وجوی ایجنت خالی باشد، حداکثر یک بار با یک مهارت ثبت‌شده و بدون محدودیت مکان جست‌وجو می‌کند؛ این نتایج صریحاً پیشنهاد گسترده‌تر معرفی می‌شوند، نه تطابق دقیق با درخواست اولیه.

اگر دریافت مستقیم نتیجه ندهد، برنامه خلاصه‌های عمومی Bing را با محدودیت دامنه و مسیر آگهی بررسی می‌کند. این نتایج برچسب «نتیجه نمایه‌شده جست‌وجو» دارند و ممکن است قدیمی باشند. برچسب «اطلاعات صفحه منبع» فقط یعنی کارت در صفحه دیده شده است؛ باز بودن استخدام یا جزئیات متن کامل را تأیید نمی‌کند. برای رزومهٔ دقیق‌تر، متن کامل آگهی را وارد کنید. شکست هر منبع صریح نمایش داده می‌شود.

## بررسی‌های قابل تکرار

تست‌های آفلاین احراز هویت، مالکیت رزومه، حفظ حقایق، سقف مصرف، خروجی و ابزارهای خراب مدل، شکست درخواست و تجزیهٔ آگهی‌ها:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

تست مرورگر از Playwright موجود و Chrome نصب‌شده استفاده می‌کند. نیازی به نصب بستهٔ Node برای اجرای برنامه نیست. اگر Playwright خارج از مسیر معمول است، `PLAYWRIGHT_MODULE` را به محل آن تنظیم کنید:

```powershell
$env:PLAYWRIGHT_MODULE = 'C:\path\to\node_modules\playwright'
node tests/ui_smoke.cjs
```

این بررسی یک حساب موقت در پایگاه دادهٔ محلی می‌سازد و هیچ درخواست مدل نمی‌فرستد. با `LIVE_SEARCH=1` جست‌وجوی زندهٔ چهار منبع را هم بررسی می‌کند. `HIRELOOP_URL` آدرس سرور محلی را تغییر می‌دهد.

این نسخه برای یک سرور و یک worker آماده شده است. داده‌ها در `data/hireloop.db` هستند؛ برای حفظ حساب‌ها و رزومه‌ها، پوشهٔ `data` را نگه دارید. پیش از انتشار عمومی، HTTPS، `COOKIE_SECURE=true`، سقف مصرف کل سرویس و سیاست نگهداری دادهٔ کاربران لازم است. اتصال واقعی هرمز تا دریافت کلید و آدرس سرویس تأیید نشده است.
