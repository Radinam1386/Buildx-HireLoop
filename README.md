# HireLoop

همراه کاریابی با مصاحبه بر اساس نقش و تجربهٔ هر کارجو: **گفتگو ← پروفایل ← آگهی مناسب با دلیل ← رزومهٔ اختصاصی ← بازخورد و اصلاح**

مصاحبه به فرانت‌اند یا تازه‌کارها محدود نیست. سطح کارآموز، تازه‌کار، میانی و ارشد در جست‌وجو لحاظ می‌شود. رزومه‌های ذخیره‌شده از تب «رزومه» دوباره باز می‌شوند، حتی اگر نتایج جست‌وجو تغییر کرده باشند. باز کردن نسخهٔ ذخیره‌شده مدل مصرف نمی‌کند.

- **Backend:** FastAPI + Pydantic + SQLAlchemy، JWT، ایجنت‌ها با LangGraph (گراف Refiner)
- **Frontend:** React (Vite) با RTL و فونت Vazirmatn
- **LLM:** هر API سازگار با OpenAI (مثلاً هرموز) — مدل هر ایجنت در `.env`

## تنظیم
۱. فایل `.env` را باز کنید و مقدارهایی که `REPLACE` دارند را پر کنید
   (`LLM_BASE_URL`، `LLM_API_KEY`، نام مدل‌ها، `EMBEDDING_MODEL`، و حتماً `JWT_SECRET`).
۲. جست‌وجوی آگهی از جابینجا، جاب‌ویژن، کوئرا، ایران‌تلنت و کاربوم انجام می‌شود. Tavily در مسیر برنامه استفاده نمی‌شود و کلید جست‌وجو لازم نیست. نام‌های قبلی `HORMOUZ_BASE_URL`، `HORMOUZ_API_KEY` و `HORMOUZ_MODEL` نیز برای تنظیم مدل پشتیبانی می‌شوند؛ فایل `.env` حفظ می‌شود.

## اجرای محلی
```bash
# بک‌اند
cd backend && python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000

# فرانت‌اند (ترمینال دوم)
cd frontend && npm install && npm run dev      # http://localhost:5173
```

## دیپلوی روی سرور
```bash
docker compose up -d --build     # سایت روی پورت ۸۰
```

## تست
```bash
cd backend && pytest -q          # کل جریان با LLM جعلی؛ بدون API key
```

## معماری کوتاه
| ایجنت | فایل | نقش |
|---|---|---|
| Interviewer | `agents.py` | مصاحبهٔ تطبیقی؛ خودش تصمیم می‌گیرد کی پروفایل کافی است |
| Matcher | `services.py` | فیلتر سخت ← embedding ← امتیاز و توضیح LLM |
| Resume Writer | `services.py` | رزومه فقط از واقعیت‌های پروفایل (+ محافظ ضدجعل برای مهارت‌ها) |
| Refiner | `agents.py` | گراف LangGraph: انتخاب اقدام (تغییر ترجیح / حذف آگهی / اصلاح رزومه / پاسخ) |

دریافت آگهی در `backend/app/jobs.py` است: HTML برای جابینجا، کوئرا و کاربوم؛ درخواست JSON رابط سایت برای جاب‌ویژن و ایران‌تلنت. هر منبع حداکثر دو عبارت و صفحهٔ اول را جست‌وجو می‌کند، حداکثر ۱۲ صفحهٔ آگهی را بررسی می‌کند و مهلت ۳۵ ثانیه دارد. متن اصلی، شناسه، بنر انقضا و تاریخ اعتبار بررسی می‌شوند؛ صفحهٔ بدون متن JobPosting وارد تطبیق نمی‌شود. پاسخ موفق پنج دقیقه در حافظه کش می‌شود. این مسیرها API عمومی تضمین‌شده نیستند.

شهر، دورکاری و سطح کارآموز با کمبود نتیجه خودکار کنار گذاشته نمی‌شوند. آگهی‌های نمونهٔ قدیمی در دیتابیس حفظ می‌شوند ولی وارد نتایج نمی‌شوند. شکست همهٔ منابع نتایج قبلی را حفظ می‌کند و با هشدار نمایش می‌دهد. وضعیت هر سایت و لینک آگهی اصلی در صفحهٔ نتایج دیده می‌شود. دریافت و بررسی آگهی مدل مصرف نمی‌کند؛ فقط حداکثر `MATCH_TOP_K` گزینه به مرحلهٔ ارزیابی مدل می‌رسند.

جست‌وجوی عمومی کاربوم و یک آگهی تازهٔ دارای JobPosting بررسی شده‌اند؛ بعضی آگهی‌های آن این داده را ندارند و فعلاً کنار گذاشته می‌شوند. مجوز تجاری استفاده از مسیرهای داخلی سایت‌ها هنوز تأیید نشده؛ شواهد و شرایط منابع در `docs/search-benchmark-api-research.md` و `docs/karboom-source-notes.md` ثبت شده‌اند.

مصرف توکن هر فراخوانی در جدول `usage` ذخیره می‌شود؛ `GET /api/usage` جمع‌ها را می‌دهد.
